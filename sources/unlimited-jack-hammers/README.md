# Unlimited Jack Hammers: sources

`mod.svg` is the mod's thumbnail, an original drawing of a rack of heavy missiles under a crossed-out
3 and an infinity sign. `mod.png` is made from it with Chrome's headless mode:

```bash
chrome --headless=new --hide-scrollbars --window-size=320,240 --screenshot=../../mods/gameplay/unlimited-jack-hammers/mod.png mod.svg
```
